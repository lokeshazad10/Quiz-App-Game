# 🎯 Quiz App Game

A simple and interactive quiz game built using **HTML**, **CSS**, and **JavaScript**. This project allows users to test their general knowledge by answering multiple-choice questions in a browser-friendly interface.

## 📌 Features

- Dynamic questions with multiple answer options
- Real-time feedback on answers
- Score tracking at the end of the quiz
- Simple and clean user interface
- Fully responsive for mobile and desktop

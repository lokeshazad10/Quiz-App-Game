Quiz App Game 🎯

A lightweight, browser-based quiz application built with HTML, CSS, and JavaScript. Play engaging quizzes, track your score, and test your knowledge—all in one place!

🌟 Features
Multiple-choice quiz experience (4 options per question)

Instant feedback and score tracking

End-of-quiz summary screen

Fully responsive: works on desktop and mobile

Easily extendable with more questions or categories

🚀 Usage
Launch the index.html file.

Select an answer for each question.

After completing all questions, view your final score.

To play again, simply refresh the page.

🗂️ Project Structure
bash
Copy
Edit
Quiz-App-Game/
├── index.html         # Main entry point
├── style.css          # Stylesheet

style.css: Provides clean, responsive styling.

main.js: Handles quiz data, question flow, score calculation, and DOM updates.
